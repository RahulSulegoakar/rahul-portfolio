## Project Overview

Next.js 16 portfolio, blog, and component registry website. Originally forked from ncdai/chanhdai.com. Uses App Router, Tailwind CSS v4, shadcn/ui, TypeScript (strict), and pnpm.

## Commands

```bash
pnpm dev                    # Dev server on port 1408
pnpm build                  # Production build
pnpm start                  # Start production server
pnpm lint                   # ESLint (flat config)
pnpm format:check           # Check formatting
pnpm format:write           # Fix formatting
pnpm check-types            # TypeScript type checking (tsc --noEmit)
pnpm registry:internal:build  # Build internal registry
pnpm registry:build         # Build full shadcn registry
```

Pre-commit hook (husky) runs lint-staged: ESLint fix + Prettier on staged files.

## Architecture

### Routing (App Router)

- `src/app/(app)/(root)/` - Home/portfolio page
- `src/app/(app)/(docs)/` - Blog, components, sponsors, testimonials
- `src/app/(llms)/` - LLM-ready content endpoints (/llms.txt, .mdx, .md)
- `src/app/og/` - Dynamic OG image generation
- `src/app/vcard/` - vCard generation

### Feature Modules (`src/features/`)

Feature-based organization with components, data, hooks, lib, and types per feature:
- `blog/` - MDX blog engine (content in `blog/content/`)
- `portfolio/` - Portfolio data files (user.ts, experiences.ts, projects.ts, etc.)
- `sponsors/` - Sponsors feature

### Component Registry (`src/registry/`)

shadcn-based system for distributing reusable components. Registry types: component, hook, block, example, lib. Each type has a `_registry.ts` file defining its entries.

**Auto-generated files - DO NOT EDIT:**
- `src/__registry__/index.tsx`
- `src/__registry__/registry.autogenerated.json`
- `public/r/*.json`

After adding/modifying registry components, run `pnpm registry:build`.

### Providers & State

- `src/components/providers.tsx` - Root providers: Jotai, next-themes, progress bar, tooltips, toaster
- State management via Jotai (atomic) and nuqs (URL state)
- Analytics: PostHog + OpenPanel (production only, consent-gated via c15t)

### Content System

- Blog posts: MDX files in `src/features/blog/content/`
- Custom remark/rehype plugins in `src/lib/` (rehype-component, rehype-code-block, rehype-npm-command, remark-component, remark-code-import)
- Syntax highlighting via rehype-pretty-code + shiki

### Key Config Files

- `src/config/site.ts` - Navigation, site metadata, GitHub repo config
- `src/config/registry.ts` - Registry namespace config
- `src/features/portfolio/data/user.ts` - Personal info (central place for portfolio data)
- `components.json` - shadcn/ui config (new-york style, zinc base color, CSS variables)

## Code Conventions

- No semicolons (Prettier config)
- No emojis in code, comments, or commit messages
- kebab-case file names, PascalCase components, camelCase functions
- Import sorting enforced by simple-import-sort ESLint plugin
- Consistent type imports (`import type { ... }`)
- Path alias: `@/*` maps to `src/*`
- Tailwind v4 syntax; utility merging via `cn()` (clsx + tailwind-merge)
- Dark/light mode support required for all UI changes

## Environment

- Node 22.x, pnpm >=9
- `.env.example` has all required variables; copy to `.env.local`
- Deployed on Vercel
