Cloning an app is not the evaluation. Someone still has to say whether the agent did the task.

While I was at AGI, Inc., I contributed to [realevals.xyz](https://realevals.xyz), a public leaderboard for AI agent performance. The replicas I was building — deterministic sandboxes with configurable behavior and real-looking data — only help if the score matches what a person would call a success.

That is what pushed me into RLHF and reward engineering. I had not done either before this role. I learned them on the job, because a wrong reward teaches the agent the wrong thing and a public leaderboard makes that mistake visible.

The useful question stopped being "does the screen look right?" and became "would this score still make sense if someone else ran the same task tomorrow?"
