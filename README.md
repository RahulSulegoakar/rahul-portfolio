# rahulsulegaokar.com

Portfolio and blog of Rahul Sulegaokar — full-stack engineer and agency founder. Design through deployment.

→ Live site: [rahulsulegaokar.com](https://rahulsulegaokar.com)

## Stack

- Next.js 16 (App Router)
- React 19 and TypeScript
- Tailwind CSS v4 and shadcn/ui
- MDX for blog posts

## Development

```bash
pnpm install
pnpm dev
```

See [DEVELOPMENT.md](./DEVELOPMENT.md) for environment variables and scripts.

## Content

- Profile, experience, projects, and tech stack: `src/features/portfolio/data/`
- Blog posts: `src/features/doc/content/blog/`
- Craft entries: `src/features/craft/data.ts`
